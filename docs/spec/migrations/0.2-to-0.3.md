# Spec migration: v0.2 → v0.3

> **Type**: minor bump (**breaking** — pre-1.0 minor-breaking allowance、 ADR-011 / G10)
> **Breaking**: あり (resource-type-rename / field-rename / scope-rename / spec file rename)
> **Effort**: low-medium (機械的 rename のみ。 意味論・shape の変更はゼロ)

v0.3 は VP v0.56.0 命名エピック (PR #939 — `World` の 3 義分解: daemon / @machine / **node**) への協調追随。 hub に効くのは federation identity 義のみで、 語彙を world → node へ一斉切替する ([ADR-021](../../adr/ADR-021-node-vocabulary-coordinated-migration.md)、 wire 戦略 = W2 flag day)。 archive: [`archive/world-tree-v0.2.kdl`](../archive/world-tree-v0.2.kdl)

## TL;DR

- **rename のみ、 shape 不変** — field 型・required・slug 構造・sync 方式はすべて据え置き
- 互換層なし (W2 一斉切替)。 旧語彙の client は spec v0.3 実装の hub に対して動かない
- ID 値の prefix も `wld_` → **`nd_`** (裁定 2-(b))。 issuer は VP 側。 hub は値を opaque に扱うため hub 実装は prefix 非依存
- VP v0.56.0 の node_identity 再発行により既存 registry 行は stale 化するため、 **データ移行は不要** (ADR-021 §2.1 の窓)

## Rename 対応表

| v0.2 (x) | v0.3 (y) |
|---|---|
| spec file `world-tree.kdl` | `node-tree.kdl` (旧 path は tombstone) |
| resource-type `vp-world` | `vp-node` |
| slug `vp/worlds/{world_id}` | `vp/nodes/{node_id}` |
| `vp-node.payload.world_id` | `node_id` |
| `vp-actor.payload.world_id` (FK) | `node_id` |
| `user.subtree` child `vp/worlds` | `vp/nodes` |
| scope `events.publish.vp-world` / `events.delete.vp-world` | `events.publish.vp-node` / `events.delete.vp-node` |
| ID prefix `wld_` | `nd_` |

## Wire (Unison hub protocol) への波及

spec と同時に hub の Unison protocol も 0.6.0 → 0.7.0 で一斉切替:

| 0.6.0 | 0.7.0 |
|---|---|
| channel `"worlds"` | `"nodes"` |
| `Discover` returns `WorldList { worlds }` | `NodeList { nodes }` |
| field `wld_id` (Register / Registered / Unregister / Unregistered) | `node_id` |
| `relay` channel の `to` / `from` | 変更なし (元々中立名。 値は node_id) |

## 据え置き (v0.3 対象外)

- `vp-actor.stand` の JoJo enum — VP #945 Stand 解体への追随は別 migration
- `reserved-path-slug "world"` — 予約継続 (解放しない。 `"node"` を追加予約)
- 過去 ADR (ADR-018/020) の本文 — immutable。 当時の語彙のまま残る
